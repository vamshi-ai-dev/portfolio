    02 — Systems

    Five production threads. Insurance, language, and documents.

    01 Aura Technologies Ltd · Jul 2025 — Present

    Claims Automation

    An AI claims desk. Intake arrives as a form, a chat, or an Outlook email. Document analysis checks the packet, flags fraud indicators, writes a validation score, and estimates reserves. An agent on LangChain and Azure OpenAI GPT-4.1 calls tools for assessment, cross-document verification, and business rules. Django services run it on Microsoft Azure.

    • Python
    • Django
    • LangChain
    • Azure OpenAI
    • Tool calling
    • Outlook API
    • Azure

    02 Aura Technologies Ltd

    Onboarding Agent

    A LangGraph insurance assistant that gathers quote inputs, walks a customer through onboarding, and answers policy questions in context. Prompts, client rules, and dialogue settings live in YAML, so the same agent can wear a different client’s process. Django on Azure Kubernetes Service.

    • LangGraph
    • Azure OpenAI
    • Django
    • YAML
    • AKS

    03 Aura Technologies Ltd

    Broker Buddy

    Policy intelligence for brokers. Custom PDF ingestion cleans and structures unstructured policy wording, then an LLM turns it into side-by-side comparisons and decision-ready notes. PostgreSQL holds the structure. Django ships on Amazon EKS.

    • LangChain
    • Azure OpenAI
    • PostgreSQL
    • Django
    • AWS EKS

    04 Amnet Digital · Hyderabad

    Conversational Analytics

    Natural language in, SQL out. A conversational analytics bot writes queries against Microsoft SQL Server and PostgreSQL, then draws the result so people can explore the data without living in a query editor. Django backend on Amazon EC2.

    • LangChain
    • OpenAI
    • MSSQL
    • PostgreSQL
    • Django
    • AWS EC2

    05 Amnet Digital · Hyderabad

    Document RAG

    Retrieval over PDFs, scans, and images. Flask APIs connect the front end to the model so a question lands on the right passage and comes back as an answer. The UI runs on EC2. GPU inference runs on RunPod.

    • Flask
    • OpenAI
    • RAG
    • AWS EC2
    • RunPod
